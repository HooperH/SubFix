# SubFix v3.2.6

- 口播、现场、单段和批量生成统一使用 v5，默认正式应用 v5 调整，不再自动降级到旧引擎。
- 修复不同说话人的字幕边界调整后可能重叠的问题。
- 检查更新不再弹出进度窗口；确认更新后显示下载进度。
- 修复本地 Qwen 依赖安装：先升级 pip，再下载依赖，支持重试和断点恢复；改善安装失败提示与首次加载检查。
- 修复安装完成阶段的脚本错误。
- 本版本源码和发行配置移除私人字幕样本、项目与时间线诊断信息，保留 v5 算法参数。

## 下载选择

- 完整安装：SubFix-v3.2.6-Full-macOS.zip，解压后打开其中的 pkg。
- 在线更新：已安装用户可在插件中选择“检查更新”；SubFix-update-v3.2.6.zip 是供更新器使用的文件。

支持 Apple Silicon Mac，安装包未签名。完整包包含 Python、FFmpeg、字幕强制对齐程序与对齐模型；本地 Qwen 语音识别依赖和识别模型仍在首次使用时联网下载。

隐私范围：本版本使用独立的脱敏源码快照。旧分支、旧标签、旧安装包及他人已经下载的副本不因此被清除。
