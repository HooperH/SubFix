# SubFix v3.3.1

## 安装

解压后打开 SubFix-v3.3.1-macOS.pkg，可直接覆盖安装，无需先卸载。
已安装 3.3.0 或更早版本的用户可在插件内使用“检查更新”。更新后关闭并重新打开插件。
支持 Apple Silicon Mac。安装包未签名；若 macOS 提示无法验证开发者，请按系统提示在“系统设置 → 隐私与安全性”中允许打开。

## 本次更新

- 本地 Qwen 按单个音频窗口顺序识别，识别进程退出后再进行 GGUF 对齐，降低模型同时驻留造成的内存压力；长音频处理速度可能下降。
- 识别与对齐前及运行中检查资源，资源不足或检查失败时停止并提示处理方法。
- 取消或超时会结束识别、对齐及其派生进程，释放后台资源。
- 修复本地 Qwen 识别时额外访问 Hugging Face 下载 Python 对齐模型的问题；识别只生成文字，时间戳使用完整包内置的 GGUF 对齐引擎，无需额外下载对齐模型。
- 保留 3.3.0 的字幕句首、句尾边界与连续字幕交接保护。
- AI 工作台统一为四项纯文字任务：完整纠错、的地得专项检测、中英翻译、简繁转换。
- 翻译与简繁转换自动判断方向，不再显示方向下拉框；依据不足时提示重试并保留原字幕。
- 本地 Qwen 依赖使用清华镜像，模型优先从魔搭下载，失败后尝试 Hugging Face。已完整安装的环境与模型继续复用。
- 保留上一版后台安装响应与卸载入口修复。

## 卸载入口无法打开

请将完整 ZIP 解压后再打开“卸载_SubFix.app”，不要只转发应用内部文件。应用使用本地签名，尚未进行 Apple 公证；若系统拒绝打开，请先确认下载来源及 ZIP 的 SHA-256 校验值。
卸载保留达芬奇项目和用户数据目录中的字幕备份、识别模型。

## 包含内容

完整包包含 Python、FFmpeg、字幕强制对齐程序与对齐模型。本地 Qwen 语音识别依赖和识别模型仍在首次使用时联网下载。
回归覆盖方向检测、取消与截断、字幕时间保留、国内源与备用源、旧环境兼容；完整界面与实际 AI 输出仍取决于达芬奇和所用模型。
