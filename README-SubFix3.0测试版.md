# SubFix v3.2.8

## 安装

解压后打开 SubFix-v3.2.8-macOS.pkg，可直接覆盖安装，无需先卸载。
支持 Apple Silicon Mac。安装包未签名；若 macOS 提示无法验证开发者，请按系统提示在“系统设置 → 隐私与安全性”中允许打开。

## 本次修复

- 新安装和失败重试的 Qwen／PyTorch 依赖改存于用户数据目录，避免依赖文件写入达芬奇脚本扫描目录，造成主线程持续扫描、进度与取消按钮无响应。
- Qwen 管理器启动时禁止写入 Python 字节码缓存，减少脚本目录变动。已完整安装的旧环境保持兼容，不强制搬迁。
- 卸载入口恢复为“卸载_SubFix.app”。双击后先显示卸载范围，点击“卸载”才会删除，默认按钮为“取消”。
- 用户目录安装无需管理员权限；系统目录安装只在确认卸载后请求权限。

## 卸载入口无法打开

请将完整 ZIP 解压后再打开“卸载_SubFix.app”，不要只转发应用内部文件。应用使用本地签名，尚未进行 Apple 公证；若系统拒绝打开，请先确认下载来源及 ZIP 的 SHA-256 校验值。
卸载保留达芬奇项目和用户数据目录中的字幕备份、识别模型。

## 包含内容

完整包包含 Python、FFmpeg、字幕强制对齐程序与对齐模型。本地 Qwen 语音识别依赖和识别模型仍在首次使用时联网下载。
本地路径隔离、真实离线 pip 安装、旧版兼容与相关回归通过；受影响电脑仍需验证界面响应。
