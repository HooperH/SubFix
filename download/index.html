  1. 安装插件

    打开 .pkg，按提示安装。3.3.9 及更早版本请下载完整安装包覆盖升级，无需卸载。

    安装包未签名。如无法打开，请确认文件来自本官网，在 Finder 中右键打开，按 macOS 提示处理。

  2. 在 Resolve 中打开

    重启 DaVinci Resolve，从脚本菜单打开 SubFix。

  3. 选择识别方式

    使用豆包云端识别时，填入豆包 API Key。本地 Qwen 需要配套的对齐模型和运行环境，首次准备需联网，也可以离线导入。
