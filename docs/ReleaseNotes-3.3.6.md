# SubFix v3.3.6

本版改进字幕断句、问题复查和生成记录，并修复字幕规整中的音频对齐及填缝规则。

- **断句优化**：改进时间状语、自然停顿和判断句的通用边界，减少两句合并、短语被拆散及助词单独成条的问题。
- **可疑字幕集中复查**：用紧凑的“问题 / 字幕”列表展示检查结果，默认显示全部提示，支持双击定位和清空 SubFix 检查标记。
- **生成记录可追溯**：记录生成运行标识、插件与引擎版本、配置指纹，便于对比和排查；记录保存在本地。
- **音频对齐规则修复**：消除默认提前量重复叠加；修复文字匹配满分导致二次复查无法采用的问题，以局部音频起音证据辅助选择候选，并保留时长、顺序及音频范围保护。
- **剪辑点辅助吸附**：仅吸附附近且不裁掉首尾发音的候选剪辑点，作为音频对齐的辅助约束。
- **填补字幕间隙**：显式勾选“消除字幕空隙”时，独立填补两秒以内的间隔，不再被音频对齐状态阻断。

音频对齐效果仍取决于对白音源和素材情况，本版不承诺所有字幕都能自动精确贴音。升级后重新打开 SubFix，并重新执行规整即可使用新规则；已有时间线不会因安装更新而自动改动。
