# SubFix v3.3.8

修复豆包标准版在长时间生成字幕时，因后续窗口提交 HTTP 504 而丢失已完成识别进度的问题。

- 每个音频窗口成功后立即保存识别结果；再次生成相同音频时，自动复用已完成窗口。
- 提交超时或遇到临时服务错误时，先查询原任务 ID；查询连续临时失败最多尝试 5 次，避免盲目重复提交。
- 保存未完成任务 ID，重新打开生成字幕后继续查询；服务端无法确认任务时保留断点并给出错误提示。
- 简化错误提示，不再展示整段网关 HTML；缓存写入失败、权限问题或损坏时明确提示。
- 保留 v3.3.7 的迷你窗口关闭修复、本地 Qwen 内存保护及现有字幕处理逻辑。

更新后请关闭并重新打开“生成选区字幕”。旧版本崩溃前未保存的识别结果无法追溯恢复；断点保存从新版运行开始生效。续跑复用识别结果，音频准备、字幕校验、对齐与分句仍会重新执行。

已有用户可在插件中点击“检查更新”。首次安装请下载 `SubFix-v3.3.8-Full-macOS.zip`（Apple Silicon，未签名安装包）。提供兼容旧更新器的更新包及完整版更新包。

验证：592 项自动化测试通过，1 项跳过；包含提交超时、查询重试、进程重启、缓存复用、写盘失败和缓存损坏场景。未使用真实付费接口进行长时间识别测试。
