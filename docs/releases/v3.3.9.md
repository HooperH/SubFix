# SubFix v3.3.9

修复字幕后处理在多个字符共用同一帧时，可能产生“字幕原始对齐范围重叠，无法安全修正边界”的问题。

- 分句遇到同轨道、同起始帧的字幕时合并文字，避免生成零时长字幕。
- 强制按字数拆行时，仅使用有效且递增的内部帧边界；无法安全拆分时保留完整文字，个别行可能超过设置的字数。
- 词边界调整无法留下有效时长时，合并相关字幕，避免强行补一帧制造重叠。
- 真正的原始范围冲突继续保留保护，并在报错中显示处理阶段、轨道、帧范围及重叠帧数，不包含字幕原文。
- 保留 v3.3.8 的豆包标准版识别缓存与中断恢复。
- 同步本机已验证的终检修复：短语气词按有效字数判断显示时长，减少统一 0.5 秒阈值造成的误报；仍提示零时长、闪现和阅读速度过快。

已有用户请在插件内点击“检查更新”，完成后关闭并重新打开“生成选区字幕”，再用原选区重试。已有豆包标准版缓存满足复用条件时会复用识别结果，后续对齐与分句仍重新执行。

首次安装请下载 `SubFix-v3.3.9-Full-macOS.zip`（Apple Silicon，未签名安装包）。同时提供兼容旧更新器的更新包及完整版更新包。

验证：626 项自动化测试通过，1 项跳过；新增 19 项回归测试，包含 120 组可重复生成的时间边界样例。未取得报错用户的完整日志和实际素材，尚未验证其现场任务；若仍失败，请反馈新版错误中的阶段、轨道、帧范围和诊断日志。
