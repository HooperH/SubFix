# SubFix v3.4.0

- 安装包不再内置模型，首次安装更轻，已有模型可继续使用。
- 新增完整版模型中心，支持 Qwen 0.6B / 1.7B 切换、识别模型在线下载和离线导入。
- 识别与对齐模型按需准备，缺少模型时会提示前往模型中心。
- 检查更新优先连接官网，下载支持取消、断点续传与校验。
- 修复协作项目媒体夹占用时字幕导入失败的问题，失败时保留原字幕。
- 修复异常音频时间戳可能让识别范围超出选区的问题。

## 安装与升级

请从 [SubFix 官网](https://subfix-by-hooper.ysjf.chatgpt.site/) 下载完整安装包，退出 Resolve 后覆盖安装，再重新打开插件。

**3.3.9 及更早版本升级到 3.4.0 需重新安装完整 PKG，本次不支持插件内一键升级。** 无需先卸载，已有配置和模型保留。

适用于 Apple Silicon Mac。安装包未签名；基础包不含任何模型权重，模型按需准备。

共享对齐模型已独立发布，可在模型中心下载，也可从 [模型下载页](https://github.com/HooperH/SubFix/releases/tag/models-v1) 下载后离线导入。模型文件约 1.84 GB，暂由 GitHub 托管，下载速度受网络环境影响；官网安装包不经过 GitHub。
